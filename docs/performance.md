# Проверка оптимизации — 19 октября 2026

Исторический отчёт версии 0.1. Текущий стек mypy/pre-commit и результаты версии 0.2
описаны в [validation.md](validation.md); приведённые ниже команды/числа не являются текущими.

Windows, Python 3.14.6, PostgreSQL 18.3. Замеры локальные, без порогов CI.
Схема БД, ORM, размер пула, API, аудит и SSO не менялись; новых зависимостей нет.

## Что изменено

- Secret/config check читает index через ls-files + один cat-file --batch вместо git show
  на каждый файл. CLI и hooks используют одну реализацию без повторного Python-процесса.
- Pre-commit проверяет staged Python/config snapshot: рабочая копия и index сохраняются.
  Ruff запускается напрямую, check/format параллельны; pytest убран из hooks.
- Миграции интеграционных тестов выполняются через Alembic API один раз за сессию.
  Каждый тест получает новый engine/session и чистые audit-данные; finally закрывает engine.
- PostgreSQL CI job независим от quality; интеграционные тесты не повторяются в общем pytest.
  uv cache/lock сохранены, повторная синхронизация команд выключена, устаревшие runs отменяются.

## Измерения

Hooks проверялись с одним staged Python-файлом (малое изменение комментария), тем же
набором зависимостей и Lefthook. До изменений — один успешный прогон; после — медиана
трёх успешных прогонов. После изменений использована временная копия репозитория,
реальные index/рабочая копия не изменялись. Небольшое различие числа tracked файлов
и прогрев кэшей не позволяют считать результаты гарантией для других машин.

Integration-набор расширен, поэтому его время не является сравнением идентичной нагрузки.
Убраны повторная пересборка схемы и семь uv/Alembic subprocess запусков на старый прогон.

## Проверки и ограничения

44 теста проходят: 39 unit и 5 PostgreSQL integration. Проверены частичное staging,
staged Ruff config, SQL whitelist, пустая страница, стабильный tie-breaker,
COUNT + SELECT без дополнительных запросов, commit/rollback аудита, лимит пула,
раздельные AsyncSession, cancellation и dispose. Миграции/OpenAPI без изменения контракта.

Индексы, pool_size, audit flush и ORM не оптимизировались без доказанной проблемы.
Не добавлены cursor pagination, eager loading по умолчанию, новые workers или сервисы.
SQL round trips сохранены там, где обеспечивают понятную семантику и транзакционность.
Ruff, Pyright, Bandit, dependency audit и secret scanning проверяются локально.
GitHub CI и Linux/macOS matrix удалённо не запускались; их ускорение пока не измерено.
Реальный SSO и нагрузочный production-профиль не подключались. Git push не выполнялся.
